## 三条最容易踩的

1. **`.env` 只在进程启动时读一次** —— 改完必须重启，不然「明明改了没生效」。
2. **迁移分两种**：开发用 `npm run db:migrate`（会改库、可能要求确认）；
   生产只能用 `npm run db:deploy`（只跑已生成的迁移文件，不会问你话）。
3. **AI Key 永远不进浏览器**。任何以 `NEXT_PUBLIC_` 开头的变量都会被编译进
   前端代码，等于把 Key 印在网页上。这个项目的 AI 调用全部在服务端转发。

> 文档里凡是要你填密钥的地方，一律写成 `这里填你的值`。
> 真密钥只存在于 `.env`（已被 `.gitignore` 忽略）和部署平台的环境变量里。
