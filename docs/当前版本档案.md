# 当前版本档案

> 版本快照：**1.0.0-rc.2**（2026-09-26，第十一阶段收尾时更新）。
> 给「半年后打开这个项目完全不记得现状的自己」看的。
> 历次发布看 [发布记录](发布记录.md)。

## 一、这是什么

面向中文网文作者的写作工具：多作品/多章节管理、自动保存、版本历史、
AI 诊断与润色（DeepSeek）。定位是**改善可读性、减少套话**，
不承诺绕过 AI 检测、不大改剧情、每个修改给出原因且可拒绝。

## 二、技术栈（含「为什么」）

| 选择 | 为什么 |
| --- | --- |
| Next.js 16 + TypeScript + Tailwind v4 | 一套代码同时管页面和接口 |
| Prisma 6 + SQLite | 换 Postgres 只改两处配置；这台机器装不了 Postgres |
| Auth.js v5（Credentials + JWT） | 邮箱密码登录，不依赖第三方登录商 |
| zod 4 | 所有接口入参在服务端重新校验，前端校验只是体验 |
| 运行依赖 7 个 | 第十阶段删过两个没用到的，别再装回来 |

## 三、功能清单（截至本版本）

- 注册 / 登录 / 退出，账号设置（改昵称、改密码、注销账号，注销级联删干净）
- 作品：创建、列表（分页）、设置（名/简介/类型 + 风格档案语气/视角/句式）、删除（带危险区确认）
- 章节：创建、编辑、自动保存（1.2 秒防抖）、手动保存（Ctrl+S）、删除、批量调序
- 编辑器：字数统计、状态灯、切章前强制落盘、断网兜底、并发保存 409 冲突提示
- 版本历史：每次保存留档、分页列表、预览、一键回滚
- AI：诊断 + 润色，结果先展示待确认，用户选择采用/复制/放弃；每日 30 次额度 + 每分钟 10 次限流
- 运维：四条 ops 命令（见下）、健康检查、上线自检、备份/恢复演练、中文错误页

## 五、第十一阶段加了什么（2026-09-26）

1. **AI 台账补监控字段**：`ok` / `durationMs` / `errorCode`（第 8 个迁移），
   失败和限流也记账（额度只认成功）
2. **四条运维命令**：
   - `npm run ops:daily` —— 日常巡检 7 节，应用没启动不算故障
   - `npm run ops:db` —— 数据库体检 7 节（完整性/容量/索引/孤立/迁移/备份）
   - `npm run ops:ai` —— AI 报表 7 节（含费用估算，口径见 [AI用量监控](AI用量监控.md)）
   - `npm run ops:release` —— 发布流水线（五连检查 + 迁移 + 自动备份 + 九步清单）
3. **运维文档七份**（含本档案），索引见 `docs/README.md`

## 七、本机环境的特殊约定（换机器前必读）

- npm 一律 `--legacy-peer-deps`；Prisma 锁 6.x；服务固定 3001 端口
- `next dev` 在本机不可用（HMR 握手失败），开发一律 `npm run app`
- 改 `.env` 后必须重启才生效
