## 一、这份政策管什么

本文说明墨语编辑器（以下简称"本服务"）在运行过程中**收集哪些数据、怎么用、存在哪、你能怎么处理**。

我们遵循**最小必要**原则：只收集让服务能跑起来所必需的数据，不收集与服务无关的信息。

---

## 二、我们收集什么

### 1. 账号信息（你主动提供）

| 数据 | 是否必需 | 用途 |
| --- | --- | --- |
| 邮箱地址 | 必需 | 作为登录名，也是账号的唯一标识 |
| 密码 | 必需 | **只存加密后的哈希值（bcrypt），我们无法还原出你的原始密码** |
| 昵称 | 可选 | 界面上显示给你自己看 |

### 2. 你创作的内容

- **作品信息**：作品名、简介、类型
- **章节正文**：你写的文字
- **版本历史**：每次保存都会保留一份正文快照（这是"写错了能退回去"的基础）
- **风格设定与人物卡**：语气、叙事视角、句式风格、人物描述等
- **AI 使用记录**：调用了多少次、什么模式、输入输出有多少字，以及**不含正文**的调用元数据

### 3. 技术性信息

服务运行时会在**服务端日志**里记录排错用的信息，例如：

- 你的用户 id（不是邮箱）、作品 id、章节 id
- 请求结果状态码、耗时
- 错误编号

**我们不在日志里记录**：你的密码、登录凭据（Cookie）、API 密钥、**正文内容**、
完整的数据库连接串。日志字段是一份固定的白名单，只有上面列的那几项。

### 4. 我们不收集什么

- 不做用户行为埋点，不做第三方统计 SDK 采集
- 不读取你设备上的其它文件
- 不使用广告或跨站追踪
- 不收集精确地理位置（浏览器层面已通过安全策略禁用定位、摄像头、麦克风权限请求）

## 三、你的正文会被发送给 AI 服务商

**这一条必须说清楚，因为它涉及你的创作内容离开本服务。**

当你点击「开始诊断」或「生成润色稿」时：

- 被处理的**那一章正文、作品名/类型/简介、以及你的风格设定**，
  会通过加密连接（HTTPS）发送给本服务配置的 AI 服务商（默认是 DeepSeek 等，
  由运营者配置），用于生成诊断建议或修改稿
- 这个调用**由我们的服务端发起**，你的浏览器不直接接触 AI 服务商，也不持有任何 AI 密钥
- 你不点这两个按钮时，正文不会被发送到任何第三方

**请你自行判断**：如果不希望某段内容被发送出去，请不要对它使用 AI 功能。
我们建议不要在正文里写入身份证号、银行卡号、住址等敏感个人信息。

> 关于第三方 AI 服务商如何处理收到的数据（保存多久、是否用于训练），
> 由其自身的隐私政策约定，不由本服务控制。建议你阅读所用服务商的条款。

## 四、数据存在哪、存多久

- 数据存储在本服务所使用的数据库中（运营者自有或租用的服务器）。
  数据库连接方式见部署文档，**数据库不对公网开放**。
- 存多久：**直到你主动删除**。没有"到期自动清"的策略。
- 删除账号时，你的作品、章节、**全部版本历史**、人物卡、风格档案、
  AI 使用记录会一并删除，**无法恢复**。
- 运营者会做定期备份，备份文件仅在需要恢复故障时使用。

## 五、你的权利（怎么操作）

| 你想做什么 | 在哪做 |
| --- | --- |
| 查看自己的数据 | 「账号」页可以看到作品/章节/版本/AI 调用条数 |
| 改昵称 | 「账号」页 → 账号信息 |
| 改密码 | 「账号」页 → 修改密码（改完所有设备需重新登录） |
| 删除某个作品 | 打开作品 → 「作品设置」→ 危险区 → 输入作品名确认 |
| 删除某一章 | 编辑页左侧章节列表，鼠标移到该章右侧的删除按钮 |
| 删除全部账号数据 | 「账号」页 → 注销账号（需输入邮箱 + 当前密码） |

**删除是不可撤销的。** 我们不做回收站，也没有人工找回的途径。
如果只是想重写，建议先把正文复制到本地再删。

需要**导出**自己写的正文时，编辑页顶栏有「导出」菜单，可以按「全书 / 当前章节」导出 `.txt` 或 `.md`；
一次导出多本作品、脚本化导出，属于后续计划（见 [已知问题](已知问题.md)）。

## 六、安全措施

- 密码使用 bcrypt（12 轮）哈希存储，我们看不到你的原始密码
- 会话用加密 Cookie 传递；改密码后旧会话立即失效
- 所有数据访问都按登录用户校验归属，"改 URL 看别人的作品"会被拦下（403 / 404）
- 已启用常见的安全响应头（禁止 iframe 嵌套、禁止 MIME 嗅探、限制来源信息）
- AI 密钥只存在于服务端环境变量中，不会进入浏览器代码

**没有任何系统是绝对安全的。** 如果发生数据泄露，我们会在确认后尽快通知你，
并说明泄露范围和应对建议。
