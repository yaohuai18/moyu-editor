# 环境变量说明

所有配置都是**环境变量**，没有配置文件。变量只放在两个地方：

- 本地开发：项目根目录的 `.env`（已被 `.gitignore` 忽略，不会进 Git）
- 线上：部署平台的环境变量页，或服务器上权限设成 `600` 的 `EnvironmentFile`

> ⚠️ **`.env` 只在进程启动时读一次。** 改完必须重启服务，
> 否则会出现「明明改了却没生效」这种最耗时间的排查。

---

## 一、四个必填

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | ✅ | 数据库地址。本地是 `file:./dev.db`（SQLite），线上换 Postgres 连接串 |
| `AUTH_SECRET` | ✅ | 会话 Cookie 的加密密钥，**至少 32 位** |
| `AI_API_KEY` | ⭕ | AI 服务密钥。不填网站照常能用，只是诊断/润色返回 503 |
| `AI_MODEL` | ⭕ | 模型名，例如 `deepseek-chat` |

生成 `AUTH_SECRET`：

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

**换掉 `AUTH_SECRET` 的后果**：所有人的登录态立刻失效，需要重新登录。
这是预期行为，不是 bug。反过来说 —— 如果怀疑会话被人伪造了，换它。

---

## 二、按需

| 变量 | 默认 | 什么时候要管 |
| --- | --- | --- |
| `AI_BASE_URL` | `https://api.deepseek.com` | 换服务商时改。**必须 https**，用 http 正文会明文上网 |
| `AI_MAX_TOKENS` | `8000` | 单次输出上限。deepseek-chat 上限是 8192，填大了会被上游直接拒 |
| `AUTH_URL` | 空 | 部署到正式域名后填 `https://你的域名`（推荐） |
| `AUTH_TRUST_HOST` | 本地 `true` | 反向代理后面没有 `AUTH_URL` 时，设 `true` |
| `MOYU_QUIET_BOOT` | 空 | 设 `1` 关掉启动自检那段日志（自动化测试里用） |

---

## 三、优先级（高 → 低）

```
进程环境变量  >  .env.production.local  >  .env.local  >  .env.production / .env.development  >  .env
```

这条规则有两个用处：

- 想临时换一个 Key 试效果，可以在启动命令前面直接写
  `AI_API_KEY=新key node ...`，它会盖掉 `.env` 里的值；
- **别用 `.env.production.local`** 做临时试验 —— 它会把已经跑着的服务
  在下一次重启时也带偏，而且很容易忘了自己写过这个文件。

## 四、三条铁律

### 1. 永远不要用 `NEXT_PUBLIC_` 前缀

`NEXT_PUBLIC_` 开头的变量会被**编译进浏览器里的 JS**。
把密钥加上这个前缀，等于把钥匙印在网页上给所有人看。

启动自检会专门扫这种错法，一旦命中直接算 fatal：

```
[FATAL] NEXT_PUBLIC_AI_API_KEY：这个变量名以 NEXT_PUBLIC_ 开头，会被打包进浏览器代码里公开，必须改名或删除
```

这个项目里 AI 调用**全部在服务端转发**（`src/app/api/ai/edit/route.ts`），
浏览器从来不持有 Key。

### 2. 不要把 `.env` 传上服务器

在平台的环境变量页里逐条填，或者用权限 `600` 的文件。
代码仓库里永远只有 `.env.example`（只有变量名，没有值）。

### 3. 别在生产继续用演示账号

`demo@moyu.local` / `moyu-demo-2026` 的密码写在文档里。
上线前删掉它，或者改一个强密码。

## 五、怎么确认配对了

启动日志会有一段自检，或者在浏览器打开 `/api/health`：

```json
{
  "status": "ok",
  "database": "ok",
  "aiConfigured": true,
  "env": { "nodeEnv": "production", "databaseKind": "sqlite" },
  "issues": [
    { "key": "DATABASE_URL", "level": "warn", "message": "生产环境用的是本地 SQLite 文件库，只适合单机单实例；…" }
  ]
}
```

- 出现 `fatal` 级问题 → HTTP 503，应用起不来
- 只有 `warn` → HTTP 200，网站能用，但那条提醒值得看一眼
- **响应里永远只有变量名和说明，没有变量值、没有连接串、没有堆栈**

判断规则写在 `src/lib/env.ts`，health 接口的实现在 `src/app/api/health/route.ts`。

## 六、本地开发的 `.env` 长什么样

```bash
DATABASE_URL="file:./dev.db"
AI_API_KEY="这里填你的值"
AI_BASE_URL="https://api.deepseek.com"
AI_MODEL="deepseek-chat"
AUTH_SECRET="这里填随机串"
AUTH_TRUST_HOST="true"
```

复制 `.env.example` 改就行。`.env.example` 里**只有变量名和注释，没有任何真实值**。
