# 功能 07：AI 诊断 / 润色

AI 诊断与轻度润色让用户在编辑页右侧面板对当前章节发起一次 AI 调用，看到执行状态、结果文本，并在面板顶部累计当日用量。

> 实测状态：❌**未实测**。这块**会花钱**，跑之前先读 Gotchas 第 1 条。

## Sub-features

- `ai-diagnose` 点 `开始诊断` → 按钮变 `分析中…` → 诊断结果出现，全页状态灯显示 `AI 处理中（诊断）`。
- `ai-polish` 点 `生成润色稿` → 按钮变 `生成中…` → `润色结果` 区块出现，状态灯显示 `AI 处理中（润色）`。
- `ai-quota-panel` 面板顶部显示 `今日 AI 用量 N / 30 次`，成功一次 N+1。
- `ai-empty-guard` 正文为空时点诊断 → 给提示，**不**白扣一次额度。
- `ai-quota-block` 用量达上限 → 出现 `今日 AI 使用次数已达上限，明天 0 点后恢复`。
- `ai-tab-clear` 切到另一章 → 右侧诊断/润色结果消失（**正确行为**，见 Gotchas 第 4 条）。

诊断结果可能带 `模板化程度` 评分（0-100，越低越自然，服务端已钳制到整数），以及形如 `模板化严重，建议整段重写后再润色` 的结论标签。

## How to get to it (user POV)

- 编辑页右侧面板 `文本诊断` 区，点 `开始诊断`。
- 编辑页右侧面板 `轻度润色` 区，点 `生成润色稿`。
- 面板顶部直接读 `今日 AI 用量 N / 30 次`。
- 结果区出现的禁用词提示：`禁用词已接入 AI（诊断与润色会尽量避开这些词）；编辑功能排在后面的阶段。`

## Driving it with browser + REST

Preconditions:

- 服务健康：`/api/health` 返回 `aiConfigured: true`（为 `false` 时本功能不可验，跳过并在报告标注）。
- 有一个已登录的 `verify+*` 一次性账号（见 SKILL.md 5.0）。
- **成本确认**：确认允许消耗 1-2 次真实 AI 额度。

| 步骤 | 选择器 / 断言 | 期望 |
|---|---|---|
| 1 | 读页面文本 | `今日 AI 用量 0 / 30 次`（新账号） |
| 2 | 正文框输入一段文本（否则触发 `ai-empty-guard`） | — |
| 3 | 点文本为 `开始诊断` 的按钮 | 按钮变 `分析中…`，状态灯 `AI 处理中（诊断）` |
| 4 | 等结果返回 | 诊断结果文本出现，按钮恢复 |
| 5 | 读面板顶部 | `今日 AI 用量 1 / 30 次` |
| 6 | 点 `生成润色稿` | `生成中…` → `润色结果` 区块出现 |
| 7 | 查库（见下） | `AiUsage` 多 1 条且最新一条 `ok=true` |

**次数 +1 的查库验法**（比看界面可靠，符合铁律一）：

```js
// 用 probe-db.cjs 的同一套连接方式
const before = await prisma.aiUsage.count({ where: { userId } });
// …点一次诊断…
const after = await prisma.aiUsage.count({ where: { userId } });
// after === before + 1，且最新一条 ok === true
```

## Gotchas

1. **成本与替代路线**：真实调用走 `POST /api/ai/edit`，用 `.env` 里的 `AI_API_KEY` 打真实模型，**按 token 计费**；每次调用写一条 `AiUsage` 记录，只有 `ok=true` 才扣当日次数。两条不花钱路线：① 项目根下 `scripts/api-test.mjs` 自带假 AI 服务（端口 `11499`，`FAKE_AI_PORT` 可改），但它只在接口测试里起；② 只验「按钮能点、状态会变、次数会记」，用真 key 跑 1-2 次即可，别做批量。
2. **不要验内容质量**：写验证技能的目的是抓回归，不是评测模型。AI 生成的文本好不好，**进不了自动断言**。禁用词是否真的避开也不要验（模型的，测不稳）。
3. **想彻底不花钱验全链**：可临时把 `AI_BASE_URL` 指向本地假服务——但改 `.env` 属禁止改动文件，**必须你本人改，且改完要改回**。`next start` 起的站点读的就是 `.env` 里的真 key。
4. **换章清空结果不是 bug**：`editor-client.tsx:605` 注释原文——「换章时清掉上一章的诊断/润色结果与打开的版本预览，避免张冠李戴」。切回来也不恢复（结果不落库）。这条容易被当成 bug 误报。
5. **失败也记账**：`AiUsage` 有 `errorCode` 字段，失败也记一条（`ok=false`）。「次数没变但多了一条记录」是正常的。
6. **未实测声明**：上面的选择器和文案来自源码（`editor-client.tsx:893/931/1588/1596/1612/1730/1745/1804/1921/2198`），**没有实际调用过 AI 接口**，因为会花钱。第一次验的时候先确认额度，跑 1 次即可；跑完把实测结果补进本文件。
